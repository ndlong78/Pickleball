# PickleUp – Huấn luyện Pickleball cá nhân

Website tiếng Việt dành cho người mới bắt đầu, với lộ trình tập Pickleball 60 phút mỗi tuần.

## Chức năng
- Giáo án 6 tuần: giao bóng, trả giao bóng, dinking, volley, chọn vị trí và chiến thuật.
- Mỗi tuần có hướng dẫn bài tập và mục tiêu cụ thể.
- Đồng hồ tập luyện, theo dõi tiến độ và kiểm tra kỹ năng.
- Lưu kết quả ngay trên trình duyệt bằng localStorage, hỗ trợ xuất dữ liệu.

## Sử dụng
Truy cập [website](https://ndlong78.github.io/Pickleball/) sau khi bật GitHub Pages, hoặc tải về và mở `index.html` trong trình duyệt.

## Bật GitHub Pages
Vào **Settings → Pages → Build and deployment** và chọn **Deploy from a branch**, nhánh **main**, thư mục **/(root)**, sau đó **Save**.

## Lưu ý
Dữ liệu lưu cục bộ theo trình duyệt/thiết bị; không tự đồng bộ giữa các máy. Website độc lập với lịch nhắc bài tập qua ChatGPT.
